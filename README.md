# Deep Learning Basics

This repository contains a collection of Jupyter notebooks demonstrating fundamental concepts of Deep Learning.

## Notebooks

Here is an overview of the notebooks included in this repository:

| Notebook | Description |
| :--- | :--- |
| **1_Neural_Network_for_Handwritten_Digits_Classification.ipynb** | Introduction to building a simple neural network for classifying handwritten digits (likely using MNIST). |
| **2_Activation_Function.ipynb** | Explores different activation functions used in neural networks. |
| **3_Derivatives.ipynb** | basics of derivatives in the context of backpropagation. |
| **4_Matrix_Multiplication.ipynb** | Understanding matrix operations essential for neural network computations. |
| **5_Gradient_Descent_for_Neural_Network.ipynb** | Implementation and explanation of Gradient Descent optimization. |
| **6_Neural_Network_from_scratch.ipynb** | Building a neural network implementation from scratch without high-level framework abstractions. |
| **7_Stochastic_Gradient_Descent_vs_Batch...** | Comparison of different gradient descent variations (Stochastic, Batch, Mini-Batch). |
| **8_Gradient_descent.ipynb** | Basic introduction to Gradient Descent. |

## Datasets

The project uses the following datasets:

-   **homeprices.csv**: Used for regression examples.
-   **homeprices_banglore.csv**: Real estate data from Bangalore, likely used for predictive modeling examples.
